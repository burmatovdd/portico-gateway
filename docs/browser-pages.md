# Страницы браузерного интерфейса

Portico предоставляет главную страницу по адресу `/`, экран подключения по адресу `/oauth/authorize` и страницы ошибок браузерного входа. Ссылка «На главную» ведёт на `/` того же сервиса. Главная страница не создаёт сессию: подключение начинается в клиентском приложении.

## Файлы

| Файл | Назначение |
| --- | --- |
| `internal/webui/pages.go` | Заголовки, описания и выбор сообщения по результату операции |
| `internal/webui/page.html` | HTML-шаблон, подписи кнопок и поля формы |
| `internal/webui/assets/portico.css` | Оформление и адаптация к размеру экрана |
| `internal/webui/assets/arch.png` | Декоративная иллюстрация без текста |

Все сообщения и подписи представлены текстом HTML. Изменение формулировок не требует генерации изображения. После изменения исходных файлов необходимо собрать образ. Статические ресурсы встроены в бинарник; внешние шрифты, CDN и JavaScript не используются.

## Ошибки

| Условие | Сообщение |
| --- | --- |
| Некорректный запрос | Ошибка запроса |
| Не пройдена проверка формы входа | Ошибка проверки запроса |
| Не завершена авторизация | Ошибка авторизации |
| Ограничено количество запросов | Обработка запроса приостановлена |
| Недоступность зависимости | Сервис временно недоступен |
| Неизвестный адрес | Страница не найдена |

HTML возвращается для браузерного запроса с `Accept: text/html`. Программные OAuth-клиенты получают прежний JSON-формат ошибок и HTTP-статус. Ответы `/oauth/token`, `/oauth/revoke`, `/mcp` и API моделей не заменяются HTML. Ошибки внешнего nginx или Kubernetes Gateway оформляются соответствующим компонентом.

Форма сохраняет проверку Origin, CSRF, защищённую cookie и PKCE. Значения параметров экранируются HTML-шаблонизатором. Пользовательские параметры и сообщения IdP не выводятся на страницу ошибки.

## Возврат в клиент

В текущих исходниках ошибка после подтверждённого OAuth-запроса может содержать кнопку «Вернуться в приложение». Callback сверяется с регистрацией клиента; возвращаются OAuth error и исходный state. При неизвестном или истёкшем запросе безопасный адрес возврата может быть недоступен, тогда используется «На главную». Кнопка не повторяет вход автоматически и не устраняет причину отказа. Изменение включено в образ 0.1.5.

## CSP в версии 0.1.6

Form-action учитывает перенаправления после отправки формы: разрешены origin Portico, доверенного IdP и только зарегистрированного клиента текущего запроса. Произвольные callback и wildcard не разрешаются. Это необходимо для браузеров, проверяющих всю цепочку OAuth по политике исходной формы. Изменение проверено модульными тестами; результат входа подтверждается в браузере после обновления.
