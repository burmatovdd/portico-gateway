# Изменения 0.1.5

Обновлены типографика браузерных страниц и возврат в зарегистрированный OAuth-клиент при ошибке. Добавлены диагностические этапы и фиксированные коды причин OAuth без записи токенов, кодов авторизации и секретов в журналы. Проверки nonce, PKCE и callback сохранены.

Сборка обоих компонентов выполняется через `containers/Dockerfile`. Перед обновлением необходимо собрать образ, указать его digest в рабочем `deploy/values.yaml` и выполнить проверки из [инструкции установки](installation.md) и [приёмки](verification.md).
