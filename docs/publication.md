# Подготовка публичного репозитория

Документация использует условные адреса `example.org`. Рабочая конфигурация не должна публиковаться вместе с проектом.

## Что необходимо завершить

- Сохранять LICENSE с текстом Apache License 2.0 при распространении проекта.
- Проверить доступность закрытого канала сообщений об уязвимостях, описанного в SECURITY.md.
- Использовать только локальный, исключённый из Git файл `deploy/values.yaml` для рабочих значений Helm: `deploy/chart/values.yaml` уже содержит универсальные значения из `deploy/values.example.yaml`.
- Исключить локальные Secret, regcred, внутренние сертификаты, адреса, Client ID, дампы, журналы и временные материалы. Проверить не только рабочее дерево, но и историю Git, если она имеется.
- Проверить права на иллюстрацию и другие ресурсы интерфейса, включая условия их распространения.
- Выпустить воспроизводимый образ из выбранного состояния исходников и указать результаты тестов и известные ограничения.
- Подтвердить вход, refresh и logout с заявленными клиентами. Не объявлять совместимость только по чтению их исходников.

Файл `.gitignore` предотвращает добавление новых локальных файлов, но не удаляет уже отслеживаемые данные и историю. Каталоги `.work/` и `.idea/` исключены из контроля версий. Наличие локальных исключений не подтверждает очистку истории Git. Перед публикацией проверить именно подготовленный индекс и все публикуемые коммиты.

Проверка документации не равнозначна аудиту безопасности кода. На текущем этапе проект предназначен для пилотного использования.

## Проверка состава публикации

После подготовки индекса Git выполнить `bash scripts/check-publication.sh`.
Требуются Git и Gitleaks. Скрипт проверяет запрещённые локальные файлы в индексе,
сканирует точное содержимое индекса и имеющуюся историю Git с маскировкой значений.
Временная копия удаляется автоматически. Отсутствие находок не заменяет ручную
проверку адресов, названий организации, лицензий зависимостей и прав на ресурсы UI.
Не отправлять архив всего рабочего каталога: исключения Git не применяются к обычному архиватору.
