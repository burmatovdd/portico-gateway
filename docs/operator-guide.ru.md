# Руководство администратора Portico Gateway

Документация разделена по задачам, чтобы установка, настройка доступа и диагностика не дублировались в нескольких инструкциях.

| Задача | Документ |
| --- | --- |
| Определить назначение компонентов | [Архитектура](architecture.md) |
| Подготовить зависимости и установить | [Установка](installation.md) |
| Настроить приложения, группы и сессии | [Провайдер идентификации](idp.md) |
| Выдать доступ к моделям | [Политика моделей](model-access.md) |
| Подключить чат или CLI | [Клиенты](clients.md) |
| Проверить установку | [Проверки](verification.md) |
| Найти причину ошибки и выполнить обновление | [Эксплуатация](operations.md) |
| Изменить текст и оформление | [Браузерные страницы](browser-pages.md) |

Начинать установку следует с зависимостей, затем настроить IdP и Portico, после этого подключать клиентов. Доступ к модели и инструментам проверяется раздельно. Параметры конкретной организации в публичное руководство не включаются.
