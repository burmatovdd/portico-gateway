# Portico Gateway

Portico Gateway предоставляет доступ к инструментам MCP и API моделей на основании корпоративной учётной записи. Провайдер идентификации проверяет пользователя, а Portico сопоставляет его роли или группы с разрешёнными сервисами и моделями.

Проект содержит два сервиса на Go:

| Сервис | Назначение |
| --- | --- |
| **core** | OAuth для MCP-клиентов, хранение пользовательских сессий, публикация и вызов разрешённых инструментов |
| **models** | Проверка пользовательского JWT, каталог доступных моделей и передача Chat Completions в LiteLLM |

Пользователи не получают служебный ключ LiteLLM. Компонент models хранит его на стороне сервера и проверяет права на каждый запрос. Компонент core передаёт целевому API проверенный пользовательский токен IdP; проверка прав на конкретные объекты остаётся обязанностью этого API.

Portico не заменяет IdP, чат или исполнитель задач. Он не создаёт агентов и Kubernetes Job, не запускает сканеры и не хранит отчёты. Strix — один из примеров подключаемого API, а не обязательная часть проекта.

## Состояние проекта

Проект находится на стадии предварительного выпуска. В исходниках реализованы OAuth для MCP, разграничение доступа к моделям, административный интерфейс и необязательный портал проверок. Админка и портал отключены по умолчанию и включаются отдельно в конфигурации. Документация описывает исходники, а не гарантированное состояние произвольного опубликованного образа. После установки необходимо выполнить проверки авторизации, обновления токенов и прав доступа в своём окружении.

## Разработка

Требуется версия Go, указанная в `go.mod`. Из корня репозитория:

```sh
go test -race ./...
go vet ./...
make build
helm lint deploy/chart
```

Интеграционные тесты используют отдельную PostgreSQL через `PORTICO_TEST_DATABASE_URL`. Без неё часть тестов пропускается. Рабочая БД для тестов не используется.
